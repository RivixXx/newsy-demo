# 🚀 Дополнительные фичи для привлечения публики и рекламодателей

> Проект: ЧИ
> Дата: 14 июля 2026 г.

---

## 1. Виральность и привлечение публики

### 1.1 📸 UGC-лента (User-Generated Content Feed)

**Что:** Публичная лента выполненных этапов — фото, видео, отзывы участников, отображаемые как Instagram-like стена.

**Зачем:**
- Социальное доказательство → новые пользователи видят, что платформа живая
- Контент генерируют сами участники → 0 затрат на создание
- Кнопка «Тоже хочу» на каждом посте → конверсия в регистрацию

**Реализация:**
- `src/app/(public)/feed/page.tsx` — публичная лента
- Агрегация `StepProgress` с `submission` (уже хранятся фото/текст)
- Masonry grid или бесконечный скролл

**Примеры:** Strava Activity Feed, BeReal, Duolingo Stream  
**Трудоёмкость:** 5–7 дней  
**Импакт:** 🔥🔥🔥

---

### 1.2 📱 Stories/Reels формат выполнения этапов

**Что:** Участники выкладывают вертикальные видео (до 60 сек) как отчёты по этапам. Организатор может включить «Stories-режим» для своего ЧИ.

**Зачем:**
- Привычный формат для аудитории 18–35
- Виральный шеринг: «Смотри мой челлендж» → VK Clips, Telegram, YouTube Shorts
- Рекламодатели ЛЮБЯТ UGC-видео с интеграцией бренда

**Реализация:**
- Новый `StepType: 'VIDEO_STORY'`  
- Мобильный плеер с вертикальным свайпом
- Обязательная загрузка через Supabase Storage (уже подключён)

**Трудоёмкость:** 7–10 дней  
**Импакт:** 🔥🔥🔥🔥

---

### 1.3 🏆 Leaderboards (живые рейтинги)

**Что:** Таблицы лидеров для каждого ЧИ: по скорости прохождения, по количеству выполненных этапов, по качеству (рейтинг организатора).

**Зачем:**
- Соревновательность → люди возвращаются чтобы подняться в рейтинге
- Шеринг: «Я в топ-10!» → привлечение друзей
- Организаторы могут давать призы по рейтингу

**Реализация:**
- `src/app/(public)/challenges/[id]/leaderboard/page.tsx`
- Запрос `UserProgress` → сортировка по `completedSteps`, `completedAt`
- Глобальный рейтинг + рейтинг внутри каждого ЧИ

**Примеры:** Strava Segments, Duolingo Leagues, Kahoot  
**Трудоёмкость:** 3–4 дня  
**Импакт:** 🔥🔥🔥

---

### 1.4 👥 Командные челленджи

**Что:** Участники объединяются в команды (2–10 человек). Прогресс считается суммарно. Внутрикомандный чат.

**Зачем:**
- Виральность ×5 — каждый участник приглашает друзей в свою команду
- HR-компании это особенно ценят (team building)
- Конкурс между командами → больше вовлечения

**Реализация:**
- Новые модели: `Team`, `TeamMember`
- Привязка к `UserProgress.teamId`
- UI приглашения по ссылке / QR

**Примеры:** Nike Run Club Groups, Habitica Parties  
**Трудоёмкость:** 7–10 дней  
**Импакт:** 🔥🔥🔥🔥

---

### 1.5 🔴 Live-стримы этапов

**Что:** Организатор может запустить прямую трансляцию для определённого этапа (старт марафона, финал конкурса, объявление победителей).

**Зачем:**
- FOMO → «Иду прямо сейчас, не пропустите»
- Push-уведомление участникам → возвращает на платформу
- Бренды могут спонсировать стримы

**Реализация:**
- Интеграция с VK Live / YouTube Live embed
- Или WebRTC через LiveKit / Agora (self-hosted)
- Расписание стримов в конструкторе

**Трудоёмкость:** 10–14 дней  
**Импакт:** 🔥🔥

## 2. Привлечение рекламодателей и брендов

### 2.1 🎯 Branded Challenges (брендированные ЧИ)

**Что:** Возможность создать челлендж с полным брендированием: кастомный цвет, лого, обложка, фон. Бренд может «скинить» страницу целиком.

**Зачем:**
- Основной продукт для крупных рекламодателей
- Ценность для бренда: «Coca-Cola Challenge на платформе ЧИ»
- Premium-тариф → основная монетизация

**Что добавить в конструктор:**
- Загрузка логотипа бренда
- Выбор цветовой схемы (primary/secondary)
- Кастомный баннер для страницы ЧИ
- Поле «Спонсор» с логотипом и ссылкой
- White-label URL: `chi.ru/brand/cocacola-challenge`

**Трудоёмкость:** 5–7 дней  
**Импакт для выручки:** 💰💰💰💰

---

### 2.2 🎁 Промокоды и купоны как награды

**Что:** Организатор может добавить промокод/купон как награду за прохождение ЧИ (скидка на товар, бесплатная доставка, бонус).

**Зачем:**
- E-commerce бренды → прямая конверсия в продажи
- Участники получают реальную ценность → больше мотивации
- Измеримый ROI для рекламодателя (каждый промокод трекается)

**Реализация:**
- Новая модель `PromoCode { code, challengeId, maxUses, usedCount, validUntil }`
- Автоматическая выдача при прохождении финального этапа
- Уникальный код на каждого участника (защита от слива)

**Примеры:** Yandex Plus промо-акции, Ozon промокоды  
**Трудоёмкость:** 4–5 дней  
**Импакт для выручки:** 💰💰💰

---

### 2.3 📊 Lead Generation через ЧИ

**Что:** Организатор может добавить кастомные поля в регистрацию на ЧИ: «Укажите должность», «Из какого города?», «Какой продукт вас интересует?».

**Зачем:**
- Бренды получают квалифицированные лиды (не просто email, а целевую информацию)
- HR-компании собирают резюме через ЧИ-собеседования
- ЧИ берёт комиссию за каждый лид

**Реализация:**
- JSON-поле `Challenge.customFields` (массив { label, type, required })
- Расширение конструктора: «Добавить вопрос для участника»
- Данные сохраняются в `UserProgress.customData`

**Трудоёмкость:** 4–5 дней  
**Импакт для выручки:** 💰💰💰💰

---

### 2.4 🔬 A/B тестирование этапов

**Что:** Организатор может создать 2 варианта этапа (разный текст, разное задание) и система автоматически разделит участников.

**Зачем:**
- Маркетологи это обожают — можно тестировать гипотезы
- «Какой формат задания даёт выше конверсию в завершение?»
- Уникальная фича — ни один конкурент этого не предлагает

**Реализация:**
- `Step.variant` (A/B) + `Step.parentStepId`
- Рандомное назначение при начале этапа
- Аналитика: конверсия по варианту

**Трудоёмкость:** 5–7 дней  
**Импакт для выручки:** 💰💰

## 3. Удержание и вовлечение

### 3.1 ⚡ Daily Challenges (ежедневный ЧИ от ЧИ)

**Что:** Каждый день платформа автоматически предлагает мини-ЧИ: простое задание (сфоткай что-то, пройди 5000 шагов, реши загадку).

**Зачем:**
- Привычка → Daily Active Users растут
- Пушит push-уведомления каждый день → retention
- Серия дней → «Streak 30 дней подряд!» → достижение

**Реализация:**
- Каталог мини-заданий (seed данные, 365 штук)
- `src/app/(dashboard)/dashboard/daily/page.tsx`
- Cron-job (или schedule): выбор случайного задания
- Streak counter в `User.dailyStreak`

**Примеры:** Duolingo daily lessons, Wordle, BeReal  
**Трудоёмкость:** 5–7 дней  
**Импакт:** 🔥🔥🔥🔥

---

### 3.2 🏅 Коллекции достижений + NFT-like бейджи

**Что:** Коллекция виртуальных бейджей: «Первый челлендж», «10 челленджей», «Марафонец», «Эко-воин». Красивый профиль с витриной достижений.

**Зачем:**
- Геймификация → люди хотят «собрать все»
- Шеринг профиля → «Смотри мои бейджи»
- Бренды могут создавать эксклюзивные бейджи (коллаборации)

**Реализация:**
- Модель `Achievement` уже есть ✅
- UI витрины в профиле
- Анимация получения бейджа (confetti + toast)
- Seed: 20–30 базовых достижений с красивыми иконками

**Трудоёмкость:** 3–4 дня  
**Импакт:** 🔥🔥🔥

---

### 3.3 🤖 AI-персонализация ленты

**Что:** «Рекомендуемые для вас» — подборка ЧИ на основе: истории участий, категорий, региона, интересов.

**Зачем:**
- Каждый видит релевантное → выше конверсия в участие
- Новые ЧИ получают трафик от AI → организаторы довольны
- Дифференциация от конкурентов

**Реализация:**
- Начать с простого: collaborative filtering (кто участвовал в X, также участвовал в Y)
- Или embeddings через OpenAI → векторный поиск по описаниям ЧИ
- Блок «Вам может понравиться» на /explore

**Трудоёмкость:** 5–7 дней  
**Импакт:** 🔥🔥

## 4. Монетизация и масштаб

### 4.1 🛒 Marketplace призов

**Что:** Магазин, где участники обменивают заработанные баллы/достижения на реальные призы: мерч, скидки, билеты.

**Зачем:**
- Замыкает цикл геймификации → баллы имеют реальную ценность
- Бренды поставляют призы → бесплатный инвентарь
- ЧИ берёт комиссию с каждого приза

**Реализация:**
- `src/app/(dashboard)/dashboard/shop/page.tsx`
- Модель `Prize { name, cost, stock, sponsorId }`
- Логика списания баллов + уведомление спонсору

**Трудоёмкость:** 7–10 дней  
**Импакт для выручки:** 💰💰💰

---

### 4.2 🔌 API + White-Label

**Что:** Открытый API для интеграции челленджей в сторонние сайты/приложения. White-label решение для корпоративных клиентов.

**Зачем:**
- Корпоративные клиенты (HR) хотят СВОЙ бренд, но вашу платформу
- API → экосистема партнёров
- Разовые лицензии 100k+ ₽

**Трудоёмкость:** 14–20 дней  
**Импакт для выручки:** 💰💰💰💰💰

---

### 4.3 🤝 Партнёрская программа для организаторов

**Что:** Организатор приводит другого организатора → получает % от его платежей в течение 12 месяцев.

**Зачем:**
- Органический рост B2B без затрат на рекламу
- Маркетинговые агентства становятся ресселлерами

**Реализация:**
- Расширение `ReferralEvent` + `eventType: 'ORGANIZER_REFERRAL'`
- Дашборд: «Моя партнёрская ссылка», статистика, выплаты

**Трудоёмкость:** 3–4 дня  
**Импакт для выручки:** 💰💰💰

## 🎯 Рекомендация: первые 4 фичи

Если делать по одной фиче за раз, вот оптимальный порядок:

1. **Leaderboards** (3–4 дня) — минимум усилий, максимум вовлечения
2. **Коллекции бейджей** (3–4 дня) — модель уже есть, нужен только UI + seed
3. **UGC-лента** (5–7 дней) — данные уже есть в StepProgress, нужна витрина
4. **Branded Challenges** (5–7 дней) — прямая монетизация, привлечение первых B2B-клиентов

Эти 4 фичи за ~16–22 дня дадут:
- **Публике:** причину возвращаться каждый день
- **Рекламодателям:** измеримый инструмент продвижения
- **Вам:** рабочую воронку привлечения B2B-клиентов
