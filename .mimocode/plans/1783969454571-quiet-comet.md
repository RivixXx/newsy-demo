### Phase 4 — Monetization & Scale (4-6 weeks)

**T18: Subscription plans for organizers**
- Seed `SubscriptionPlan` with 3 tiers: Стартер (990₽/мес), Бизнес (4990₽/мес), Корпоратив (29000₽/мес)
- Create `src/app/(public)/pricing/page.tsx`
- Integrate YooKassa recurring payments
- Middleware: check subscription limits when creating challenges
- Switch from one-time publish payment → freemium (1 free challenge, then subscription)
- Est: 7-10 days

**T19: Organizer verification**
- Add `isVerified Boolean @default(false)` to Organizer model (Prisma migration)
- Document upload flow: organizer uploads ОГРН/ИНН docs → Supabase Storage
- Admin panel: verification review section
- Verified benefits: badge on profile/cards, auto-approve challenges, priority in catalog
- Est: 3-4 days

**T20: Reports/Complaints system**
- New Prisma model: `Report` (reporterId, challengeId?, userId?, reason, description, status)
- UI: "Пожаловаться" button on challenge card → modal with reason selection
- Admin panel: complaints section with actions (REVIEWED/RESOLVED/DISMISSED)
- Auto-hide challenges at N complaints threshold
- Est: 3-4 days

**T21: Escrow mechanics**
- New Prisma model: `EscrowBalance` (challengeId, userId, amount, status)
- On payment: hold funds in NEWSY account
- Release to organizer on challenge completion (minus commission from `CommissionConfig`)
- Refund to participant per `CancellationPolicy` (FULL_REFUND_24H / 7D / NO_REFUND)
- Est: 5-7 days

**T22: Organizer analytics dashboard**
- New page: `src/app/(dashboard)/dashboard/organizer/[id]/analytics/page.tsx`
- Metrics: conversion funnel (views→registrations→start→finish), step-by-step dropout, geography, registration dynamics, satisfaction score
- Est: 5-7 days
